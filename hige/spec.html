方針

画像データ不足時の対応

実データが揃うまでは、このセクションは 匿名化・部分カット（顔の口周りだけ切り取り）の画像2-3枚のみに留める。無理に3部位揃えない。

よくある質問
— 懸念の先回り —

FAQ 6件（アコーディオン式）

  1. 痛みはどのくらい？ → 業界最高峰マシンの冷却機能で、輪ゴムで弾かれる程度。「想像より痛くない」と多くの方に言われます。
  2. 何回で効果が出る？ → 個人差はありますが、多くの方が3〜5回で実感。髭は8〜10回で永久的な減毛が目安です。
  3. 初回でローンや高額コースを勧められる？ → ありません。都度払い制で、気に入らなければそれで終わりです。
  4. 他の客と顔を合わせることは？ → 完全1名貸切制のため、来店から退店まで他のお客様と会うことはありません。
  5. 白髪の髭にも効く？ → 白髪部分には光脱毛は反応しません。黒髪が残っている今がラストチャンスです。
  6. 当日キャンセルは？ → 前日までのご連絡でキャンセル料無料です。

レイアウト

  • アコーディオン式（クリックで開閉）
  • 質問の左に「Q」、回答の左に「A」をゴールドで
  • 背景: 微妙に薄いグレー（他セクションとの区別は境界ではなく色温度で）

制作時の注意事項
— CRITICAL NOTES —

セクション境界を曖昧にする実装テクニック

  • 背景色の連続性: 全セクションを黒 (#0d0d0d ~ #1a1a1a) で繋ぎ、明確な「区切り線」は使わない
  • オーバーラップ配置: 前セクションの写真・装飾が次セクションに少しはみ出す
  • スクロール連動フェードイン: `IntersectionObserver` で要素が見えたら opacity: 0→1, translateY: 30px→0
  • 見出しも小さく: セクションごとの大きなH2見出しを置かず、本文が見出しとして機能する

Meta広告LP審査対策

  • 画像内の文字比率は20%以下
  • 「永久脱毛」は機器メーカー定義に準拠して使用
  • Before/Afterは「個人差あり」明記・医療広告ガイドライン準拠
  • 「100%」「絶対」などの断定語は使用しない

AI感排除チェックリスト

  • ☐ Heroのモデル写真に「Hasselblad / 80mm / f/2.8」等の撮影指定が入っているか
  • ☐ 小画像はすべてフリー素材からの実写になっているか
  • ☐ 顧客の声・事例に固有情報（年齢・職業・回数）が入っているか
  • ☐ 手書き・アナログ装飾を使っていないか（真面目基調のため）
  • ☐ セクションタイトルにメタ英語ラベル（PAIN POINTS等）が残っていないか
  • ☐ 番号「01/02/03」が小さく・中身の文章が主役になっているか

A/Bテスト候補

  • Hero訴求軸: 「最後の決断だ」vs 「10年後に後悔させない」
  • 料金表示位置: S5中盤 vs S6直後（Before/After後）
  • Before/Afterの部位順: 口周り先頭 vs 顎先頭
